# Truax Marketing — Content Engine (hosted site)

Static site behind **truax-marketing-content-engine.netlify.app**.

- `index.html` — the Content Topic Engine dashboard (themes, opportunity map, draft prompts). Regenerated daily by the 6am run.
- `library/` — the Content Library vault (finished posts + visuals, with one-click Copy).

Netlify auto-deploys this repo on every push to `main`. Do not hand-edit on the server; edits flow through the daily run / Cowork.
